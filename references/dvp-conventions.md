# 台达 DVP 编程约定（写程序时反复用到的那些坑）

## 1. `DPLSY`：取数顺序与三菱相反

**`DPLSY S1 S2 D` —— S1 = 输出频率(Hz)，S2 = 脉冲数，D = 脉冲输出口。**

* **`S2 = K0` 表示连续输出**（无限脉冲），靠断开驱动条件停止 —— 这是回零碰限位的标准写法。
* 因此**距离参数写成 0 会变成"一直走"**。所有"距离/脉冲数"类参数都要做**最小值钳位**：
  在参数搬运段用工作副本 `MOV Dn Dm` + `LD= Dn K0 → MOV K1 Dm`，遇 0 自动按 1 处理。
* 距离类参数按 16 位比较处理，控制在 32767 以内。

**脉冲完成标志**（脉冲走完后保持 ON，直到该 DPLSY 指令断开才复位，**必须由程序手动复位**）：

| 脉冲口 | 完成标志 |
|---|---|
| Y0 | M1029 |
| Y1 | M1030 |
| Y2 | M1102 |
| Y3 | M1103 |

### 起步延时定时器的两个作用

每个定量移动工步在发脉冲前都要等一小段（本项目固定 10ms）：

1. 给**方向输出**留建立时间 —— **换向丢步基本都出在这里**；
2. 用它的**输出接点**（`AND Tn`）做"完成判断的延时门" —— 否则上一工步残留的
   完成标志会把当前工步直接跳过（尤其**连续两步用同一个脉冲口**时必然踩）。

改延时不用改寄存器，直接把对应 `TMR Tn K1` 的 `K1` 改成 `K3`（30ms）/`K5`（50ms）。

## 2. 定时器时基与特殊继电器

| 项目 | 说明 |
|---|---|
| T0~T199 | **100ms** 时基 |
| T200~T239 | **10ms** 时基（要 10ms 精度只能用它） |
| M1038 | **ON 会把 T200~T245 切成 1ms 时基** —— 用 10ms 时基的程序里**必须保持 OFF** |
| M1000 | RUN 期间常 ON |
| M1002 | 上电首次扫描脉冲（初始脉冲） |
| M1033 / D1033 | STOP→RUN 时是否清除非保持区（默认 OFF = **会清除**） |

## 3. 数据寄存器保持区（DVP-ES2）

| 区间 | 掉电保持 |
|---|---|
| **D0~D407** | ✗ 非保持（掉电清零，**STOP→RUN 也会清**） |
| **D408~D599** | ✓ 保持 |
| D600~D999 | ✗ 非保持 |

**所有"用户要调、且希望记住"的参数必须放在 D408~D599**。放在非保持区的话，
PLC 停一下再启动就恢复成默认值 —— 调好的参数会莫名其妙"丢"，很难排查。

工作副本 / 中间计算量可以放非保持区（每次都会重算）。

> 注意：符号表里 D 寄存器的初值列填 `0`。**下载时不要勾选「下载符号初值 / 清除保持区」**，
> 否则参数会被清成 0（程序里有 0 钳位保护，不会撞机，但轴不会动，需在 HMI 重设）。

## 4. 步进（STL）

* DVP 的步进继电器 S0~S1023 配合 `STL` / `RET` 使用。
* `STL Sxx` 打开该步的**步进母线**，其后的支路都受它控制；`RET` 结束一段步进程序。
* 在 `.mpu` 里 **`STL` / `RET` 各自独占一个网络**。
* ISPSoft 的梯形图编辑器可以正常输入 `STL` / `RET`（已实测）。

## 5. 参数寄存器的两条命名纪律（避免踩过的坑）

1. **"速度"类寄存器不要放进参数钳位段**。速度是"设定值 × 速度定值(D506)"由 `DMUL` 算出来的，
   如果又用钳位段的 `MOV` 覆盖它，就等于把算好的实际频率冲掉了。
   **只有距离/时间类需要"搬工作副本 + 钳位"**，速度类一律由速度换算段直接算出。
2. **一条件多输出写在同一个网络**是可以的（会自动加 TYPE=29 聚合节点），
   但**中间不能再插接点**（见 `il-to-network.md`）。

## 6. I/O 分配纪律（吃过两次亏）

**元件的物理分配只能以现场接线或用户确认的指令表为准，不能靠注释表推断。**
注释表里没有的元件号（比如某些 Y 点）尤其不能猜。

做法：
* 先把 **I/O 分配表**列出来请用户过一遍，再往下写程序；
* 程序、注释、文档里**一律用"轴名"表述**（上下轴 / 前后轴），器件号只集中在 I/O 分配表这一处，
  改接线时只动分配表 + 相关的 X/Y 操作数；
* 想知道某个 Y 点是干什么的，**先去指令表里 grep 它出现在哪些支路、和哪条 DPLSY 配对**，
  再向用户确认（实测经验：某台四轴机的 Y30~Y33 才是四轴方向，而且与脉冲写在同一条支路上，
  光看注释表推不出来）。
